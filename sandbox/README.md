# Sandbox

Development exploration, not maintained examples or reproducible research runs:

- `notebooks/`: manual REPL/package checks and Python behavior investigations.
  `Path.ipynb` and `ast.ipynb` are preserved empty placeholders.
- `scripts/bedrock/`: direct SDK and LangChain API trials using legacy settings.
- `archive/prompts/`: historical prompt variants; runtime prompts stay beside their architecture or tool.

Files are preserved as historical working material. They may require credentials,
old APIs, or local paths; some make network calls or install/uninstall packages.
They are not executed by the project test launcher.
